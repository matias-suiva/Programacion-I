## 📂 Estructura del Repositorio

### 1\. HTML5 - Estructura y Semántica Web

Construcción de los cimientos y jerarquía de contenidos en el navegador.

* **Conceptos clave**: Documentación semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`), metadatos (`charset`, `viewport`), listas (`<ol>`, `<ul>`, `<dl>`), tablas, enlaces, formularios e integración multimedia (`</dl></ul></ol></footer></aside></article></section></main></nav></header>
### 2\. CSS3 - Diseño, Maquetación y Layouts

Estilización y arquitectura visual para interfaces web modernas.

* **Conceptos clave**:  
  * Modelo de Cajas (`content`, `padding`, `border`, `margin`).
  * Posicionamiento en CSS (`static`, `relative`, `absolute`, `fixed`, `sticky`, `z-index`).
  * Modos de visualización (`block`, `inline`, `inline-block`, `none`).
  * Maquetación avanzada: **Flexbox** y **CSS Grid** (diseño bidimensional, unidades `fr`, `gap`).
* **Ejercicios Destacados**:  
  * 📌 `Nav Fijo`: Implementación de menú de navegación persistente mediante `position: fixed` y jerarquía con `z-index`.
  * 🎬 `La Casa de Papel`: Ejercicios de posicionamiento absoluto/relativo y rejilla con CSS Grid.
  * ❄️ `El Eternauta - Refugio de Supervivientes`: Tarjetas interactivas con distribuciones flexibles en Flexbox, efectos `hover` y transiciones con `transform: scale()`.

### 3\. JavaScript &amp; Manipulación del DOM

Inyección de interactividad y comportamiento dinámico del lado del cliente.

* **Conceptos clave**:  
  * Captura y validación de datos del DOM: `document.getElementById()`, `.value`, `.trim()`.
  * Eventos de usuario (`click`), manejo de formularios con `preventDefault()`.
  * Selección y manipulación en lote: `querySelectorAll()`, `forEach()`, alternancia de clases con `classList.toggle()` y temporizadores `setTimeout()`.
* **Proyectos Destacados**:  
  * ⚡ `El Generador de Luz de Nikola Tesla`: Circuito lógico interactivo para control del estado visual de luminarias mediante lectura e inspección del DOM.
  * 🏆 `TP Mundial 2026 - DT Por Un Día`: Aplicación web oficial para inscripción y validación en tiempo real de postulantes a Director Técnico de la Selección Argentina.

### 4\. PHP - Lógica de Programación y Backend

Desarrollo de algoritmos y procesamiento del lado del servidor.

* **Conceptos clave**:  
  * Sintaxis de inicio ``, comandos de salida (`echo`), variables y tipos de datos.
  * Operadores de asignación, aritméticos, de comparación y lógicos (`AND`, `OR`, `NOT`).
  * Incremento y decremento (`++$a`, `$a++`).
  * Estructuras condicionales (`if`, `else`, `elseif`, `switch`).
  * Estructuras repetitivas (`while`, `do-while`, `for`, `foreach`).
* **Ejercicios y TP Integrador**:  
  * ⚡ `Serie Ejercicios Tesla`: Retos progresivos de lógica ("La chispa inicial", "La energía de dos números", "La bobina de Tesla", "La secuencia de energía").
  * 🅿️ `TP Integrador SEOM LAB`: Sistema de Estacionamiento Medido desarrollado en PHP puro. Incluye validación de rangos de box (1000-1999), cobro por períodos dinámicos con bucles `while`, menú interactivo con `switch` y procesamiento masivo de vehículos con `for`.

## 🔧 Control de Versiones con Git

Guía rápida de comandos Git utilizados para la gestión del repositorio y sincronización con GitHub:

```
# 1. Clonar el repositorio localmente
git clone https://github.com/matias-suiva/Programacion-I.git

# 2. Consultar el estado de los archivos en el árbol de trabajo
git status

# 3. Agregar cambios al área de preparación (Staging)
git add .

# 4. Confirmar los cambios con un mensaje descriptivo
git commit -m "feat: agrega ejercicios de PHP y maquetación CSS"

# 5. Enviar las confirmaciones al repositorio remoto en GitHub
git push origin main

```

## ⚙️ Entorno de Trabajo e Instalación

Para ejecutar los proyectos de PHP y servidor local:

1. **Servidor Local**: Instalar [XAMPP](https://www.google.com/url?sa=E&amp;q=https%3A%2F%2Fwww.apachefriends.org%2F).
2. **Iniciar Servicios**: Iniciar **Apache** (y **MySQL** de ser requerido) desde el *XAMPP Control Panel*.
3. **Ubicación de Archivos**: Clonar o guardar las carpetas del proyecto dentro del directorio raíz del servidor local: `C:\xampp\htdocs\Programacion-I`
4. **Acceso Web**: Abrir el navegador e ingresar a: `http://localhost/Programacion-I/` *(En caso de conflicto de puertos en el puerto 80, modificar a puerto 8080 en `httpd.conf` y acceder vía `http://localhost:8080/Programacion-I/`)*.
